# 냉장고 구조대

1인 가구의 냉장고·냉동고·기본 상온 재료를 한 화면에서 소진 체크하고, 유통기한이 임박한 재료를 우선 반영해 오늘·내일 두 끼(점심·저녁) 메뉴를 제안하는 미니 웹앱입니다. 토스 앱처럼 쿨그레이 배경(`#F2F4F6`)·순백 카드(24px 라운드)·넉넉한 여백·큰 터치 타겟으로 구성했고, 화면에는 꼭 필요한 정보만 남겼습니다.

## 이번 개편에서 바뀐 것

### 1. 정보 다이어트
- 상단 대시보드는 `0 / 37개 처리` 큰 숫자와 진행 바, `🚨 급하게 처리할 재료 N개` 한 줄로 정리했습니다. 곧 소진·소량 남음·두 끼 kcal 요약 칩과 급한 재료 칩 줄은 없앴습니다.
- 끼니 카드의 탄단지는 `약 499kcal · [3색 미니 바] · 단 36g` 한 줄입니다. 탄/지 %와 그램 4줄 표기는 없앴습니다.
- 경고는 `⚠️ 속 불편 조합 +1`처럼 **한 줄**로 접히고, 누르면 근거·팁이 그 자리에서 펼쳐집니다. 추천 메뉴 배지·긴 안내 문단은 없앴습니다.

### 2. 목표 대비 보충 음식 → 추가 섭취
- `🎯 오늘 목표 대비` 아래 **`🍪 추가 섭취`** 영역이 생겼습니다. 부족분 보충 칩(`＋ 🐠 고등어`)이나 간식 칩(사과·귤·청포도·단쉐·삶은달걀)을 누르면 그 자리에 칩으로 담기고, 담긴 칩의 `✕`로 한 번에 뺍니다.
- 담을 때 토스트의 `취소`, 뺄 때 `되돌리기`로 바로 되돌릴 수 있고, 칼로리·탄단지는 `오늘 목표 대비` 진행 바에 즉시 반영됩니다.

### 3. 목표 수정 — 목적별 프리셋
- `목표 수정` 시트 맨 위에 프리셋 카드 세 장: **균형 유지**(1,800kcal · 탄 225g · 단 90g · 지 60g), **단백질 집중·감량**(1,500kcal · 탄 150g · 단 105g · 지 53g), **활동량 많음·유지**(2,000kcal · 탄 250g · 단 100g · 지 67g). 탭하면 바로 적용됩니다.
- 세부 조정은 `직접 조정` 아코디언에서 하루 칼로리와 탄·단·지 **비율(%)** 슬라이더로 합니다. 비율 합은 100%로 자동 유지되고 g이 실시간 계산됩니다.

### 4. 외식 기록 — 메뉴를 적으면 계산
- `🍗 외식`을 누르면 외식 기록 시트가 열립니다. `청년치킨 후라이드 4조각, 소스 2팩, 맥주 1잔`처럼 적으면 쉼표·`+`로 나눠 항목별 추정 kcal·탄·단·지로 분해합니다(내장 메뉴·브랜드 사전 60여 종, 단위 조각/그릇/인분/팩/잔/캔/병/봉/줄/개/세트).
- 항목별 `−/+` 수량 보정, `✕` 빼기, 합계와 `이 끼니까지 넣으면 단백질 12g 더 필요해요` 안내, 빠른 선택 칩(치킨 4조각·순대국밥·파스타·샐러드볼·버거세트·맥주 1잔)을 제공합니다.
- `기록하기`를 누르면 끼니가 외식으로 기록되고 메뉴명·kcal·탄단지가 끼니 카드, `오늘 목표 대비`, 지난 기록에 그대로 합산됩니다. `메뉴 없이 외식으로만 표시`도 남겨 두었습니다.

### 5. 잔량 퍼센트 슬라이더
- 재료 탭과 `✅ 먹었음` 시트에서 남은 양을 **0~100% 슬라이더**로 드르륵 조절합니다(5% 스냅, `100% 가득 · 50% 반 남음 · 0% 다 씀`, 먹었음 시트에는 100/75/50/25/0% 빠른 버튼).
- 통·팩·병·봉·소분 재료와 1개 이하로 남은 재료가 슬라이더로 동작하고, 2개 이상 남은 다개입 재료는 기존 `−/+` 스테퍼를 씁니다. 1개 이하가 되면 자동으로 슬라이더로 바뀝니다.
- 0%가 되면 처리 완료, 일부만 남으면 `다 먹음` 버튼이 떠서 한 번에 넘길 수 있습니다. 예전 `소량`·`1개 반`·`절반 남음` 저장값은 그 뜻대로 퍼센트로 이어집니다.

## 기능 정리

- 재료 탭: 위치별 필터(냉장고·냉동고·기본상온), `미처리만 보기`, 재료 추가·수정·삭제, 이름에서 이모지 자동 매핑
- 식단 탭: `오늘 (11/21) | 내일 (11/22)` 세그먼트로 한 날짜의 두 끼만 보기, `🔄 다시 짜기`, 날짜 자동 전환
- 끼니 카드: `점심 · 11/21` + 배지, 큰 제목, `⏱ 10분 · 노쿡 · 난이도 쉬움` 메타, `✏️ 직접 입력`·`🔄 다른 메뉴`, 한 줄 탄단지, 한 줄 경고, 재료 칩, `📖 레시피 보기`, `🍗 외식 | ✅ 먹었음`
- `📖 레시피 보기`: 조리 시간·방식·난이도, `✓ 냉장고에 있어요`(남은 양) / `🛒 사와야 해요`, `STEP 1,2,3…`, 팁 — 기본 레시피 21종
- 먹었음 시트: 퍼센트 슬라이더로 남은 양 조절, 다개입 재료는 `−/+`·`반 개 먹음`·`다 먹음`, 0% 재료가 있으면 안 먹은 다른 끼니 자동 교체
- 재료 칩 `✕`: 소진 확인 팝업(`네, 소진됐어요` = 소진 + 끼니 자동 교체 / `아니요, 이 메뉴에서만 뺄게요`)
- 소진된 재료가 남은 끼니: 취소선·`소진됨` + `다른 레시피로 바꾸기`
- 급한 재료 사인: 두 끼에 안 쓰인 급해요·곧 소진 재료를 한 줄 띠로 표시, 누르면 급한 순 목록으로
- `📅 지난 기록`: 캘린더(먹음·외식·미기록·간식 점, 목표 달성 초록 테두리)와 리스트(월 요약·하루 평균). 외식은 메뉴와 추정 영양까지 남고, 빠뜨린 끼니를 `먹었음`·`외식`으로 늦게 표시 가능
- 모든 상태는 브라우저 `localStorage`에 자동 저장(퍼센트 잔량·개수·외식 기록·추가 섭취·직접 등록 메뉴·날짜별 식단·하루 목표)

빌드 도구 없이 `index.html` 한 파일로 동작합니다. GitHub Pages(브랜치 `main`, 루트)로 서빙됩니다.

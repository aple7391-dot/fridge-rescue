# 냉장고 구조대

1인 가구의 냉장고·냉동고·기본 상온 재료를 한 화면에서 소진 체크하고, 유통기한이 임박한 재료를 우선 반영해 오늘·내일 네 끼(점심·저녁) 메뉴를 제안하는 미니 웹앱입니다.

- 재료 탭: 위치별 필터(냉장고·냉동고·기본상온), `미처리만 보기`, 항목별 처리 스위치, 재료 추가·수정·삭제
- 식단 탭: 오늘·내일 점심/저녁 추천, `다른 메뉴` 교체, `배달·외식` 스킵, `이거 먹음`으로 레시피에 쓴 재료 한 번에 처리
- 상단 대시보드: 전체 소진 진행률, 급하게 처리할 재료 개수
- 모든 상태는 브라우저 localStorage에 자동 저장

빌드 도구 없이 `index.html` 한 파일로 동작합니다. GitHub Pages(브랜치 `main`, 루트)로 서빙됩니다.

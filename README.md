# 냉장고 구조대

1인 가구의 냉장고·냉동고·기본 상온 재료를 한 화면에서 소진 체크하고, 유통기한이 임박한 재료를 우선 반영해 오늘·내일 네 끼(점심·저녁) 메뉴를 제안하는 미니 웹앱입니다. 토스 앱처럼 쿨그레이 배경(`#F2F4F6`)·순백 카드(24px 라운드)·넉넉한 여백·큰 터치 타겟으로 구성했습니다.

- 재료 탭: 위치별 필터(냉장고·냉동고·기본상온), `미처리만 보기`, 항목별 처리 스위치, 재료 추가·수정·삭제
- 개수 재료 `소량` 단위: `2개 → 1개 → 소량 → 0개` 스테퍼에 `1개 반` 단계를 더해 반 개(0.5) 단위로 조절. `1개`에서 `−`를 누르면 주황 `소량` 단계(스테퍼 배경도 주황)로 내려가고 `소량 남음` 뱃지·`다 먹음` 버튼이 뜨며, `소량`에서 한 번 더 `−` 하면 처리 완료. 가운데 숫자를 누르면 `1개 ↔ 1개 반`처럼 반 개 표시를 켜고 끌 수 있음
- `✅ 먹었음` 시트: 여러 개 남은 개수 재료도 `소량(반 개)` 버튼과 스테퍼로 반 개만 쓴 기록이 가능(`2개`에서 소량 → 대시보드·소진 체크에 `1개 반 남음`으로 저장, 그 상태에서 다시 소량 → `1개`). `소량`만 남은 재료는 `소량까지 다 씀(소진)` 버튼으로 마무리
- 식단 탭: `오늘 (11/20) | 내일 (11/21)` 세그먼트로 한 날짜의 두 끼만 집중해서 보기, `🔄 다시 짜기`는 오른쪽 위
- 끼니 카드: `점심 · 11/20` + `추천 메뉴` 배지, 큰 제목, `⏱ 10분 · 팬 · 난이도 쉬움` 메타, `✏️ 직접 입력`·`🔄 다른 메뉴` 보조 버튼, 재료 칩, `📖 레시피 보기`, `🍗 외식 | ✅ 먹었음`
- 탄단지 요약: 끼니마다 `약 499kcal` · `탄 34% · 단 28% · 지 38%` pill과 3색 미니 바, `탄 42g · 단 36g · 지 21g` 그램 표시. 재료 37종과 장보기 추가 재료 모두에 1인분 추정 영양이 붙어 21종 기본 레시피·직접 입력 메뉴 모두 실시간 계산(성인 여성 한 끼 기준, 1일 2끼 중심)
- 속 불편·영양 경고: 큰 박스 나열 대신 카드 안 **한 줄 칩 요약**(`⚠️ 속 불편 조합` · `⚖️ 단백질 부족` · `🔁 매운 끼니 연속`)으로 접고, `자세히 ⌄`를 누르면 근거·팁이 펼쳐짐. 판단 기준: ① `⚠️ 속이 불편할 수 있는 조합` — 매운맛+유제품, 기름진 재료 여러 개+유제품, 매운맛+짠맛, 빵·면+기름, 산미+유제품, 찬 생채소+매운맛, 짠 재료 3가지 이상 ② `⚖️ 탄단지` — 단백질 16g·15% 미만, 지방 38% 초과, 탄수화물 68% 초과·18% 미만 ③ `🔁 다음 끼니와 겹쳐요` — 외식으로 비운 끼니는 건너뛰고 실제로 먹는 다음 끼니와 매운맛·기름진 재료·빵·면 연속, 유제품과 자극 교차, 두 끼 합산 단백질 36g 미만·지방 36% 초과·탄수화물 65% 초과를 확인. 단백질이 부족하면 냉장고에 있는 재료를 골라 `＋ 🥚 계란 더하기`로 그 끼니에 바로 추가
- 먹은·외식 끼니는 접힌 아코디언으로 표시: 메뉴명·상태 배지와 탄단지 미니 바·% 한 줄만 보이고, 탭하면 재료·상세가 펼쳐짐(`접기`로 다시 접힘)
- `🎯 더 챙기면 좋은 비율`: 그 날 두 끼 합산 탄단지(탄 50·단 25·지 25% 기준)와 비교해 `단백질 +8% 약 14g` · `탄수화물 +9% 약 46g` · `지방 −7%`처럼 모자라거나 넘치는 비율을 한 줄로 안내하고, **지금 남아 있는 재료** 중 그 비율을 보태 줄 재료(단백질 → 계란·두부·닭가슴살·참치·쉐이크·우유, 탄수화물 → 밥·모닝빵·감자·과일, 채소·식이섬유 → 샐러드·버섯 등)를 칩으로 추천. 칩을 누르면 그 날 아직 안 먹은 끼니에 바로 더해짐
- 급한 재료 사인: 그 날 두 끼에 안 쓰인 `급해요`·`곧 소진` 재료를 카드 사이 `🚨 오늘 안에 정리` 한 줄 띠(재료 칩 + `›`)로 표시하고 누르면 급한 순 목록으로 이동
- `📖 레시피 보기` 바텀시트: 조리 시간·방식·난이도, 재료를 `✓ 냉장고에 있어요` / `🛒 사와야 해요`로 구분, `STEP 1, 2, 3…` 단계별 조리 순서, `💡 이렇게 하면 더 좋아요` 팁. 기본 레시피 21종 모두 수록, `직접 입력` 끼니는 재료·메모 중심 안내
- `✅ 먹었음`으로 레시피에 쓴 재료 한 번에 처리
- 먹었음 시트: 덜어 쓰는 재료(개수 없는 재료·남은 개수가 1개 이하인 개수 재료)는 행마다 `조금 먹음(남음)` / `다 먹음(소진)` 두 버튼으로 한 번에 구분하고, `✕`로 이 끼니에 안 쓴 재료를 뺍니다. `다 먹음`은 저장과 동시에 소진 처리되고, `조금 먹음`은 먹음 횟수만 +1 쌓습니다(개수 재료는 반 개를 써서 `소량` 단계로 내려감). 여러 개 남은 재료도 `−/+` 스테퍼, `소량` 버튼, `다 먹음`으로 먹은 만큼(반 개 단위)만 기록
- 재료 탭의 `💧 소량 · N회` 뱃지와 옆의 `다 먹음` 버튼으로 언제든 소진으로 넘길 수 있고, 상단 대시보드에 소량 남은 재료 개수를 표시. `소량`은 아직 냉장고에 있는 재료로 취급되어 레시피에서 취소선·`소진됨`이 뜨지 않음
- 재료 칩: 먹은 끼니의 칩은 `소량`·`다 먹음`으로 남은 상태를 보여주고, 칩의 `✕` → 소진 확인 팝업(`네, 소진됐어요` = 소진 처리 + 이 재료를 쓰는 다른 끼니 자동 교체 / `아니요, 이 메뉴에서만 뺄게요`), 끝의 `＋ 재료`로 끼니에 재료 추가. 아직 안 먹은 끼니에 소진된 재료가 남아 있으면 취소선·`소진됨`과 카드 안 알림 바로 표시
- 상단 대시보드: 전체 소진 진행률, 급하게 처리할 재료 개수
- 모든 상태는 브라우저 localStorage에 자동 저장

빌드 도구 없이 `index.html` 한 파일로 동작합니다. GitHub Pages(브랜치 `main`, 루트)로 서빙됩니다.

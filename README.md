# 냉장고 구조대

1인 가구의 냉장고·냉동고·기본 상온 재료를 한 화면에서 소진 체크하고, 유통기한이 임박한 재료를 우선 반영해 오늘·내일 네 끼(점심·저녁) 메뉴를 제안하는 미니 웹앱입니다. 토스 앱처럼 쿨그레이 배경(`#F2F4F6`)·순백 카드(24px 라운드)·넉넉한 여백·큰 터치 타겟으로 구성했습니다.

- 재료 탭: 위치별 필터(냉장고·냉동고·기본상온), `미처리만 보기`, 항목별 처리 스위치, 재료 추가·수정·삭제
- 식단 탭: `오늘 (11/20) | 내일 (11/21)` 세그먼트로 한 날짜의 두 끼만 집중해서 보기, `🔄 다시 짜기`는 오른쪽 위
- 끼니 카드: `점심 · 11/20` + `추천 메뉴` 배지, 큰 제목, `⏱ 10분 · 팬 · 난이도 쉬움` 메타, `✏️ 직접 입력`·`🔄 다른 메뉴` 보조 버튼, 재료 칩, `📖 레시피 보기`, `🍗 외식 | ✅ 먹었음`
- 탄단지 요약: 끼니마다 `약 499kcal` · `탄 34% · 단 28% · 지 38%` pill과 3색 미니 바, `탄 42g · 단 36g · 지 21g` 그램 표시. 재료 37종과 장보기 추가 재료 모두에 1인분 추정 영양이 붙어 21종 기본 레시피·직접 입력 메뉴 모두 실시간 계산(성인 여성 한 끼 기준, 1일 2끼 중심)
- 속 불편·영양 경고: 문제가 있을 때만 카드 안에 박스로 표시. ① `⚠️ 속이 불편할 수 있는 조합` — 매운맛+유제품, 기름진 재료 여러 개+유제품, 매운맛+짠맛, 빵·면+기름, 산미+유제품, 찬 생채소+매운맛, 짠 재료 3가지 이상 ② `⚖️ 탄단지` — 단백질 16g·15% 미만, 지방 38% 초과, 탄수화물 68% 초과·18% 미만 ③ `🔁 다음 끼니와 겹쳐요` — 외식으로 비운 끼니는 건너뛰고 실제로 먹는 다음 끼니와 매운맛·기름진 재료·빵·면 연속, 유제품과 자극 교차, 두 끼 합산 단백질 36g 미만·지방 36% 초과·탄수화물 65% 초과를 확인. 단백질이 부족하면 냉장고에 있는 재료를 골라 `＋ 🥚 계란 더하기`로 그 끼니에 바로 추가
- 급한 재료 사인: 그 날 두 끼에 안 쓰인 `급해요`·`곧 소진` 재료를 카드 사이에 `🚨 오늘 안에는 다 먹어야 해요` 카드로 표시(이름·메모·배지) + `🧺 소진 체크에서 정리하기`
- `📖 레시피 보기` 바텀시트: 조리 시간·방식·난이도, 재료를 `✓ 냉장고에 있어요` / `🛒 사와야 해요`로 구분, `STEP 1, 2, 3…` 단계별 조리 순서, `💡 이렇게 하면 더 좋아요` 팁. 기본 레시피 21종 모두 수록, `직접 입력` 끼니는 재료·메모 중심 안내
- `✅ 먹었음`으로 레시피에 쓴 재료 한 번에 처리
- 먹었음 시트: 덜어 쓰는 재료(개수 없는 재료·1팩·1모처럼 남은 개수가 1인 재료)는 행마다 `조금 먹음(남음)` / `다 먹음(소진)` 두 버튼으로 한 번에 구분하고, `✕`로 이 끼니에 안 쓴 재료를 뺍니다. `다 먹음`은 저장과 동시에 소진 처리되고, `조금 먹음`은 먹음 횟수만 +1 쌓입니다. 계란·모닝빵처럼 여러 개 남은 재료는 `−/+` 스테퍼와 `다 먹음` 버튼
- 재료 탭의 `🥛 소량 · N회` 뱃지와 옆의 `다 먹음` 버튼으로 언제든 소진으로 넘길 수 있고, 상단 대시보드에 소량 남은 재료 개수를 표시
- 재료 칩: 먹은 끼니의 칩은 `소량`·`다 먹음`으로 남은 상태를 보여주고, 칩의 `✕` → 소진 확인 팝업(`네, 소진됐어요` = 소진 처리 + 이 재료를 쓰는 다른 끼니 자동 교체 / `아니요, 이 메뉴에서만 뺄게요`), 끝의 `＋ 재료`로 끼니에 재료 추가. 아직 안 먹은 끼니에 소진된 재료가 남아 있으면 취소선·`소진됨`과 카드 안 알림 바로 표시
- 상단 대시보드: 전체 소진 진행률, 급하게 처리할 재료 개수
- 모든 상태는 브라우저 localStorage에 자동 저장

빌드 도구 없이 `index.html` 한 파일로 동작합니다. GitHub Pages(브랜치 `main`, 루트)로 서빙됩니다.
